# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Владельцы домашних животных в Беларуси, которые потеряли питомца или нашли чужого — часто в стрессе, с телефона, нужны быстрый контакт и понятная география. Вторичные аудитории: волонтёры, приюты и администраторы платформы (модерация, объявления, настройки).

## Product Purpose

DorogaDomoy.by помогает быстрее вернуть питомца домой: карта и список объявлений «пропал» / «найден» / приюты, контакты в один тап, листовки с QR, профили питомцев и адресники. Успех — меньше времени от объявления до живого контакта и ясных следующих шагов без лишней когнитивной нагрузки.

## Positioning

Локальная белорусская платформа с картой, сценарными регистрами (пропал / найден / приют / адресник) и «дорогой домой» как продуктовой метафорой — не общий маркетплейс объявлений и не международный агрегатор без регионального фокуса.

## Operating Context

- Браузер (desktop + mobile-first от 360px); вход в т.ч. через Telegram (встроенная WebView-страница).
- Основные потоки: лендинг → поиск на карте/списке → карточка объявления → звонок/мессенджер; создание объявления; «мои питомцы» / адресник; листовка для печати и шаринга; админка модерации.
- Языки интерфейса: русский, белорусский, английский (i18n обязателен для всего UI-текста).

## Capabilities and Constraints

- Frontend: React 18, TypeScript, Vite 6, Tailwind CSS v4, Leaflet, Radix UI.
- Backend: FastAPI, SQLAlchemy, JWT; роли user / volunteer / shelter / admin.
- Объявления с фото, фильтрами, модерацией, жалобами, архивом; избранное; приюты и shelter-pets; генерация листовок; Web Share изображения.
- Стили только через токены (`src/shared/styles/tokens.css`); UI — атомы/молекулы/организмы в `src/shared/ui/`; без хардкода строк вне i18n.
- Доступность: ориентир WCAG 2.1 AA (контраст, focus-visible, aria-label, тап ≥ 44px).
- Открыто: глубина native/PWA, AI-матчинг по фото, массовые оповещения по радиусу — в дорожной карте, не обещать в UI без реализации.

## Brand Commitments

- Имя: **DorogaDomoy.by** / «Дорога домой».
- Голос: короткий, конкретный, без канцелярита; срочность без истерики в сценарии «пропал».
- Визуальные якоря (зафиксированы в `docs/ux-guidelines.md`): оранжевый бренд CTA (`#ff9800`), медальон/жетон, «гравировка», пунктирная «дорога», пара шрифтов **Manrope** (display) + **Inter** (UI) — смена шрифтов только осознанным ребрендингом.
- Три сценарных регистра + адресник: rose / sky / emerald / латунь; бренд-оранжевый не смешивается со сценарным акцентом на одном элементе.

## Evidence on Hand

- Код и токены: `src/`, `landing/`, `docs/ux-guidelines.md`, `docs/LOST_VS_FOUND_DESIGN.md`.
- Нет сторонних кейс-стади / отзывов клиентов в репозитории — не выдумывать testimonials, цифры успеха или лицензии в UI.

## Product Principles

1. Один экран — одно главное действие; контакт с автором максимум в один тап.
2. Снижать стресс: ясная иерархия, дозировка сценарного цвета, короткие глаголы.
3. Мобильный приоритет и i18n (ru/be/en) без поломки вёрстки на длинных строках.
4. Токены и переиспользуемый UI — единый источник правды; hex в компонентах запрещён.
5. Не обещать нереализованные возможности (AI, push, оповещения) как уже доступные.
