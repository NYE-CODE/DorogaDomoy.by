# UX/UI Guidelines — DorogaDomoy.by

Обязательные принципы для всех новых и изменяемых компонентов (Фазы 1+).
Документ дополняет существующую дизайн-систему (`src/shared/ui/`) и токены (`src/shared/styles/tokens.css`), не заменяет их.

---

## 1. Эмоциональный UX в стрессе

Пользователь, потерявший питомца, находится в панике. Интерфейс обязан снижать когнитивную нагрузку, а не добавлять её.

- **Один экран — одно главное действие.** Главные CTA получают наивысший визуальный вес:
  - связь с автором объявления (позвонить / Telegram / Viber);
  - «Подать объявление»;
  - «Сгенерировать листовку».
- Главный CTA — самая крупная и контрастная кнопка на экране: `Button` с `variant="default"` (брендовый `--color-primary`) и размером `cta` (h-12). На экране такой CTA **один**; остальные действия — `outline` / `ghost`.
- Второстепенное (шаринг, жалоба, «показать ещё») визуально приглушено и не конкурирует с главным действием.
- Никаких лишних шагов до контакта: телефон/мессенджер доступны максимум в 1 тап от карточки.
- Тексты — короткие, конкретные, без канцелярита: «Позвонить», а не «Связаться с владельцем по телефону».

## 2. Доступность (WCAG 2.1 AA)

- Контраст текста и статусных элементов — **не менее 4.5:1** (для крупного текста ≥ 18.66px bold / 24px — 3:1).
- Запрещён бледно-серый текст на белом фоне. Минимально допустимый приглушённый цвет — `--color-text-muted` (#5c5c6b); `--color-text-disabled` — только для действительно неактивных элементов, не для контента.
- Все интерактивные элементы — с видимым фокусом: `focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2` (примитивы из `_primitives/` уже содержат это — переиспользуем, не переопределяем).
- Иконки-кнопки без текста — **всегда** с `aria-label` (текст берётся из i18n, не хардкодится). Декоративные иконки — `aria-hidden="true"`.
- Статусы («Пропал», «Найден», «Ищет дом») не кодируются одним лишь цветом: цвет + текстовая подпись.
- Тап-цель на мобильных — не менее 44×44px.

## 3. Единообразие форм (радиусы)

| Элемент | Класс | Радиус |
|---|---|---|
| Крупные карточки, модалки, попапы карты | `rounded-2xl` | 16px |
| Кнопки, инпуты, селекты, бейджи-действия | `rounded-lg` | 8px |

Промежуточные радиусы (`rounded-md`, `rounded-xl`) в новых компонентах не используем без явной причины. Вложенные скругления: внутренний радиус ≤ внешний минус паддинг.

## 4. Единая интерактивность

- Все кликабельные элементы: `transition-all duration-200`.
- Hover-реакция — изменение цвета/фона или прозрачности (например, `hover:bg-primary-hover`, `hover:opacity-90`). Без «прыгающих» layout-эффектов (изменение размеров, margin) на hover.
- Активное состояние (`active:`) допустимо лёгким затемнением/scale, но не обязательно.
- Курсор: `cursor-pointer` только у настоящих интерактивных элементов.

## 5. Изоляция отступов

- У **атомов и молекул** (`src/shared/ui/atoms/`, `molecules/`) — никаких внешних `margin` (`m-*`, `mt-*` и т.п.) в корневом элементе.
- Расстояния между элементами задаёт **родитель**: `flex`/`grid` + `gap-*` (или `space-y-*` в исключительных случаях для потоков текста).
- Компонент может принимать `className` для позиционирования снаружи, но сам по умолчанию «плотный».

## 6. Мультиязычность

- **Ни одной строки текста в JSX/атрибутах без i18n.** Включая `aria-label`, `title`, `placeholder`, `alt`, тексты тостов.
- Механизм проекта: `const { t } = useI18n()` из `@/app/providers/I18nContext`; `t` — **объект**, доступ через свойства: `t.petCard.callButton` (не `t('...')`).
- Новые ключи добавляются в `src/shared/i18n/translations.ts` сразу во **все три локали**: `ru`, `be`, `en`. Типы выводятся от `ru` — пропуск локали даст ошибку компиляции.
- Плейсхолдеры — по существующей конвенции: строка с `{placeholder}` и ручной заменой (`.replace('{date}', ...)`).
- Вёрстка должна выдерживать тексты разной длины (be/en длиннее ru на 10–30%): `truncate`/`line-clamp` для ограниченных зон, без фиксированных ширин под конкретную строку.

## 7. Мобильный приоритет

- Проектируем от **360px** ширины: базовые (безпрефиксные) классы — мобильная версия, десктоп — через префиксы.
- Брейкпоинты — стандартные Tailwind (кастомных в проекте нет): `sm` 640px, `md` 768px, `lg` 1024px, `xl` 1280px.
- Граница «мобильный/десктоп» в JS-логике — `useIsMobile()` из `@/shared/hooks/use-mobile` (<768px, синхронно с `md`). Не создавать собственные media query.
- Главный CTA на мобильном — во всю ширину (`w-full`) и в зоне досягаемости большого пальца (низ экрана / sticky-панель, как в существующем `MobileBottomNav`).

## 8. Технические инварианты (напоминание)

- Стили и цвета — только через токены: CSS-переменные из `tokens.css` + маппинг `@theme` в `globals.css`. Никаких hex-значений в компонентах. Tailwind v4, файла `tailwind.config.ts` нет.
- UI-примитивы переиспользуем: `@/shared/ui/atoms|molecules|organisms` (обёртки над `_primitives/`), с нуля не пишем.
- Новый код — только в `src/` с алиасом `@/`; корневые `components/`, `context/` — deprecated-шимы.
